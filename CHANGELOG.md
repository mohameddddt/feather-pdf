# Changelog

## 0.1.0 - 2026-11-08

First release.

- Continuous page view with fit width, fit page, actual size and zoom (10% to 800%).
- Contents sidebar built from the PDF's bookmarks.
- Search with highlighted matches; long documents are searched without freezing the window.
- Text selection (drag, double-click for a word, Ctrl+A for a page) and copying.
- Reading position, zoom and fit mode remembered for each document.
- Full screen reading mode.
- Dark and light themes following the Windows setting.
- Page cache with a fixed 32 MB budget, and automatic release of PDFium's per-page data.
